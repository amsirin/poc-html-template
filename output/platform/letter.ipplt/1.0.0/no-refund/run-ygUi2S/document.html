เรียน คุณ ผู้รับตัวอย่าง

เอฟดับบลิวดีได้รับใบคำขอเอาประกันชีวิตของคุณเรียบร้อยแล้ว และขอขอบคุณอย่างยิ่งที่ได้มอบความไว้วางใจกับเอฟดับบลิวดี

ข้อมูลใบคำขอเอาประกันชีวิต

เลขที่ใบคำขอAPP-DEMO-001
ผู้ขอเอาประกันคุณ ผู้เอาประกันตัวอย่าง
แบบประกันแบบประกันสำหรับการทดสอบ

จากการพิจารณาใบคำขอเอาประกันชีวิตและเอกสารประกอบ เราไม่สามารถพิจารณารับประกันได้ และขอแจ้งการเลื่อนการพิจารณารับประกันชีวิตออกไป

เอฟดับบลิวดีพร้อมที่จะมอบบริการที่ดีให้กับคุณเสมอ และหวังเป็นอย่างยิ่งว่า เราจะได้มีโอกาสมอบประสบการณ์ที่ดีให้กับคุณในครั้งต่อไป สอบถามรายละเอียดเพิ่มเติม ได้ที่ศูนย์บริการลูกค้าเอฟดับบลิวดี โทร. 1351 เราพร้อมดูแลคุณทุกวัน 08.00 - 20.00 น.
